# Haircut Booking System 💇🏽‍♀️

A React-based web application designed to manage haircut bookings and customer appointments.

## 📌 About the Project

The Haircut Booking System was developed as a web application to provide a simple way for customers to manage haircut appointments.

The project focuses on building a responsive user interface and handling navigation, API communication, booking-related interactions, and user notifications.

## 🛠️ Technologies Used

* React
* JavaScript
* React Router
* Axios
* Bootstrap
* React-Bootstrap
* React Toastify

## ✨ Features

* 📅 Haircut appointment booking
* 🧭 Client-side navigation
* 📱 Responsive user interface
* 🔗 API communication using Axios
* 🔔 User notifications
* 🎨 Bootstrap-based styling

## 📂 Project Structure

The application is built using React and follows a component-based structure.

Key technologies include:

* **React** for building the user interface
* **React Router** for navigation between pages
* **Axios** for communicating with APIs
* **Bootstrap and React-Bootstrap** for styling and responsive layouts
* **React Toastify** for displaying user notifications

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/Mmasetshaba28/HaircutBooking.git
```

Navigate into the project:

```bash
cd HaircutBooking
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will then run locally in your browser.
